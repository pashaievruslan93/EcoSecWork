# Pashaiev_Ruslan_Site

Навчальний веб-сайт, створений в рамках дисципліни
**«Інформаційні технології у системі забезпечення економічної безпеки держави»**

## 📌 Структура сайту

🔹 **1. Головна сторінка**

* Інформація про студента:

  * Руслан Пашаєв
  * Факультет інформаційних технологій
  * Група 1-6мз

🔹 **2. Резюме**

* Вбудований PDF файл з резюме

🔹 **3. Аналітичний звіт (Японія)**

* 5 основних загроз економічній безпеці
* 5 рекомендацій щодо покращення

## 🌐 Навігація

Сайт має зручне меню для переходу між сторінками.

## ⚙️ Технології

* HTML5
* CSS3

## 🚀 Запуск

Сайт відкривається через файл `index.html` або через GitHub Pages.
