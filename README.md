# Навчальний сайт — Руслан Пашаєв

Статичний сайт складається з трьох сторінок:

1. `index.html` — інформація про студента.
2. `resume.html` — сторінка з PDF-резюме.
3. `report.html` — аналітичний звіт щодо економічної безпеки Азербайджану.

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте всі файли з цього архіву в репозиторій.
3. Перейдіть у `Settings` → `Pages`.
4. У полі `Source` виберіть гілку `main` та папку `/root`.
5. Збережіть налаштування та відкрийте посилання, яке надасть GitHub Pages.
